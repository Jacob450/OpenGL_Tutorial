# OpenGL 3D Triangle

A beginner-level **OpenGL graphics project** featuring a textured 3D triangle, camera controls, and real-time rendering.

## Overview

This project is a hands-on introduction to **OpenGL and real-time 3D graphics programming**. It renders a textured 3D triangle and includes a working camera system that allows the scene to be viewed from different positions and angles.

The project was developed while following an OpenGL tutorial as a way to build a practical foundation in graphics programming and understand the fundamental components of a modern graphics pipeline.

## How It Works

The application defines the geometry and texture information required to render the triangle and sends this data to the GPU.

Shaders process the geometry and determine how the final pixels are rendered. Transformation matrices are used to position the triangle within the 3D scene and project it onto the screen.

A camera system controls the **view transformation**, allowing the user to move around the scene and observe the rendered object from different perspectives.
